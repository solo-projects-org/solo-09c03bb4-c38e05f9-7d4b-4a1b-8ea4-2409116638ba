# 道路巡检桥接上报复核

道路巡检中，同一裂纹可能被多名数据员重复上报，长链的邻近上报会被归并成一件事。
本工具帮助复核员优先排查**会改变事件归并范围的关键上报（疑似桥接上报）**：
移除某条上报后，如果它所在的连通组会分裂成至少两个非空组，这条上报就是桥接，
它的去留直接决定归并成一件事还是多件事。

## 判定规则

- 同一路段内，两条**未撤回**上报：平面距离 ≤ 5 米 **且** UTC 时差 ≤ 10 分钟（含边界）→ 相连；
- 连通关系按此传递构成连通组；
- **疑似桥接** = 图论中的割点：移除该上报后，其**原连通组**分裂成 ≥ 2 个非空组
  （普通边缘点/叶子移除后只剩一个组，不算桥接；其他不相干连通组不计入分裂组）；
- 页面展示每条桥接上报分裂后的各组成员上报号（即其关联来源）。

## 修订语义

- 同一上报号可多次出现（不同修订号），**生效行 = 修订号最大的行**；
- 高修订可更正坐标/时刻/路段，也可撤回（`withdrawn=1`，撤回后不参与连通）；
- 迟到的旧修订照常落库留痕，但永远不会重新生效，无法恢复旧证据。

## 一致性设计

- **原子上传**：整份 CSV 校验通过才在一个事务（`BEGIN IMMEDIATE`）内提交；
  任何一行有错或写入失败，整批回滚，不留半截数据；
- **快照读取**：每次查询在单个只读事务内取数，桥接结论与分裂证据来自同一份
  已提交快照，不会被并行上传切成两半；
- **WAL + busy_timeout**：读写交错不报错；SQLite 文件持久化，进程/容器重启后
  已提交数据原样保留（compose 中挂载命名卷 `bridge-data`）。

## CSV 格式

表头必需列（中英文均可）：`report_id/上报号, revision/修订号, segment_id/路段号,
x, y, ts_utc/UTC时刻, withdrawn/撤回标记`

- `x, y`：平面米坐标（有限数值）；
- `ts_utc`：ISO 8601，如 `2026-11-19T08:30:00Z`；无时区按 UTC 计；
- `withdrawn`：`0/1`、`true/false`、`yes/no`，留空视为未撤回；
- 同一文件内不允许重复的 `上报号+修订号`；跨文件重复上传同键记录为幂等覆盖。

示例见 `examples/sample.csv`。

## 运行（Docker Compose）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

数据保存在命名卷 `bridge-data`（容器内 `/data/app.db`），重启不丢。

## 本地开发与自测

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload          # 本地起服务（DB 在 ./data/app.db）
pytest tests/ -q                       # 运行自测
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 上传表单、路段列表、上传历史 |
| POST | `/upload` | 上传 CSV（表单 file 字段）；失败整批拒绝并展示原因 |
| GET | `/segments/{路段号}` | 疑似桥接上报（含分裂后各组名单）+ 有效上报表 |
| GET | `/api/segments` | 路段统计 JSON |
| GET | `/api/segments/{路段号}/bridges` | 桥接结论 JSON |

## 已知限制

- 单文件上传上限 20MB；建图与割点计算在内存中进行（Tarjan O(V+E)），
  单路段上报量极大时会成为性能瓶颈，届时需加分页/离线计算；
- 同一 `上报号+修订号` 内容冲突的重复上传以最后一次为准（幂等覆盖），
  如需拒绝冲突可在 `db.save_upload` 中把 `INSERT OR REPLACE` 改为冲突报错；
- 未做登录鉴权，仅适合内网/单机复核使用。
